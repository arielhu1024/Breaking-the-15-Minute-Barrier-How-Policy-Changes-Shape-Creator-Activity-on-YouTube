# Breaking the 15 Minute Barrier: How Policy Changes Shape Creator Activity on YouTube

## Overview

This project examines how YouTube's removal of the 15-minute upload limit affected creator behavior.

Using data collected through the YouTube Data API, Kafka, and PySpark, I constructed a large-scale creator-month panel dataset and applied causal inference methods to evaluate policy impacts.

---

## Dataset

- 1.27M+ videos collected
- 494 creators
- 82,664 videos
- 11,856 creator-month observations

---

## Methodology

- Difference-in-Differences (DID)
- Fixed Effects Models
- Poisson Regression
- Negative Binomial Regression

---

## Tech Stack

Python
SQL
Kafka
PySpark

---

## Key Findings

- General creators reduced posting frequency after the policy change.
- Professional creators increased posting frequency.
- Platform policy changes generated heterogeneous impacts across creator groups.
